## Problem ucznia

Rodzice często zauważają, że ich dzieci mają trudności ze zrozumieniem i zapamiętaniem materiału, co wpływa na wyniki w nauce. Uczniowie skarżą się na chaotyczne notatki, które uniemożliwiają im powtórzenie materiału przed egzaminami. W takim kontekście warto przyjrzeć się metodzie notatek Cornella, która pozwala na lepsze organizowanie informacji.

## Czym są notatki Cornella?

Notatki Cornella to sprawdzona technika, która ułatwia zapamiętywanie i przetwarzanie informacji. Została opracowana na Uniwersytecie Cornella i polega na podzieleniu kartki na trzy sekcje: notatki,  i pytania. 

### Szablon na kartkę A4

Oto jak wygląda przykładowy szablon notatek Cornella:

```
----------------------------------------
|                Pytania              |
| (lewa kolumna - 2,5 cala)            |
|                                      |
----------------------------------------
|               Notatki               |
| (prawa kolumna - 6,5 cala)          |
|                                      |
|                                      |
|                                      |
|                                      |
|                                      |
----------------------------------------
|                         |
| (dolna część - 2 cale)               |
|                                      |
----------------------------------------
```

W tej metodzie uczeń najpierw zapisuje najważniejsze informacje w sekcji „Notatki”. Następnie, po lekcji, formułuje pytania, które pomogą mu lepiej zrozumieć materiał. Na końcu podsumowuje całość, co sprzyja utrwaleniu wiedzy.

## Błędy, które zabijają sens notatek

Mimo że metoda jest efektywna, można popełnić kilka powszechnych błędów:

1. **Brak struktury** – Notatki powinny być uporządkowane, aby łatwo było się do nich odwoływać. Brak podziału na sekcje sprawia, że notatki są chaotyczne.
   
2. **Zbyt mało informacji** – Uczniowie często ograniczają się do zapisywania jedynie kluczowych słów. Notatki powinny zawierać pełne zdania i koncepcje, aby były zrozumiałe w przyszłości.

3. **Niewłaściwe pytania** – Formułowanie pytań zbyt ogólnych lub niezwiązanych z materiałem utrudnia efektywne przyswajanie wiedzy.

4. **Brak podsumowania** – Pomijanie tej sekcji sprawia, że trudno jest zrozumieć całość materiału i znaleźć kluczowe informacje.

## Jak wykorzystać notatki w praktyce?

Aby skutecznie wdrożyć tę metodę, warto:

- **Przeznaczyć 5 minut na przygotowanie** sekcji „Pytania” przed lekcją.
- **Zarezerwować 15 minut po lekcji** na  i zapisanie najważniejszych informacji.
- **Wydrukować szablon** i mieć go zawsze pod ręką podczas lekcji.

## Checklist do efektywnego korzystania z notatek Cornella

- [ ] Upewnij się, że używasz odpowiedniego szablonu.
- [ ] Podziel kartkę na trzy sekcje przed rozpoczęciem notowania.
- [ ] Zapisuj pełne zdania, a nie tylko słowa-klucze.
- [ ] Formułuj pytania, które pomogą Ci w zrozumieniu materiału.
- [ ] Po lekcji poświęć czas na  najważniejszych informacji.

Dzięki wykorzystaniu notatek Cornella uczniowie mogą lepiej zrozumieć i zapamiętać materiał, co wpłynie na ich wyniki w nauce. Więcej informacji o tej metodzie można znaleźć w artykule na [Wikipedia](https://pl.wikipedia.org/wiki/Notatki_Cornella).
